# Publication and copyright boundary

Prepared **11 October 2026** at the owner's request.

- `Uwaziman1/dukasole` is the private full-code repository. Its history is preserved; it is not used as a public fork base.
- `Uwaziman1/dukasole-showcase` is a new public repository with a fresh history and an explicit source allowlist: documentation, nine synthetic-data screenshots, seven selected JavaScript implementation files (plus a supporting error type), one SQL excerpt, focused tests and two reference test specifications. The 13 October extension adds only pure report/fictional-fixture/currency contracts, not the integration server, tokens, vault, business exporter or private provider responses.
- No server, authentication implementation, application SQLite schema, whole Finance/Sales/Stock implementation, complete browser workspace, tenant database, auth key, password file, KYC attachment or private evidence archive is included.
- The hosted site contains only static walkthrough HTML/CSS/JavaScript and the same safe screenshots. It cannot operate the till or authenticate into the private application.
- Selected source/modules and screenshots are reviewed before pushing. Ignore patterns are an additional guard, not proof that a secret cannot be committed. They do not remove information already present in history.
- Copyright restrictions are retained in `LICENSE` and package metadata (`UNLICENSED`). No MIT or Apache license is added. This is not technical copy prevention; applicable law, GitHub's terms and third-party rights still apply.
- Making the old repository private does not recall prior clones, cached information or other copies. No deletion of history, automatic secret rotation or change to business data is performed.
- GitHub secret scanning and push protection should be enabled where supported. These detect supported secret patterns; they do not detect every credential, personal identifier, sensitive document or unsafe screenshot. No paid plan or Advanced Security purchase is authorized by this publication task.

Verified repository security status on 11 October 2026:

- Public `dukasole-showcase`: secret scanning **enabled**, push protection **enabled**, confirmed by authenticated GitHub repository metadata.
- Private `dukasole`: GitHub returned HTTP 422, **"Secret scanning is not available for this repository."** Neither feature is claimed as enabled there. No subscription, paid feature or visibility relaxation was used to bypass this limitation.
